
- `fix:` 기존 풀이 수정/개선
- `docs:` README 등 문서 수정

## 📌 규칙

- 프로그래머스 등 **공개 문제** 풀이만 올립니다.
- 실제 채용 코딩 테스트(회사가 낸 문제) 지문·답안은 올리지 않습니다.
- 문제 지문 전문을 복사하지 않고, 링크와 요약으로 대체합니다.
- 해결하지 못한 문제는 해설을 참고한 뒤 다시 직접 구현합니다.
- 더 좋은 풀이가 있다면 리팩토링을 진행합니다.
