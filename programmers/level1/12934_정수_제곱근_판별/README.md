# 정수 제곱근 판별 (12934)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12934
- 난이도: Lv.1

## 문제 요약
임의의 자연수 `n`이 어떤 자연수 `x`의 제곱인지 판별한다.
- `n`이 `x^2`이면 `(x+1)^2`을 반환한다.
- `n`이 어떤 자연수의 제곱도 아니면 -1을 반환한다.

## 접근
- `i`를 1부터 늘려가며 `i * i`가 `n`을 넘을 때까지 반복한다.
- 도중에 `i * i == n`이 되면 `n`이 `i`의 제곱수이므로 `(i + 1)^2`을 반환한다.
- 반복이 끝날 때까지 못 찾으면 -1을 반환한다.
- `n`의 범위가 커질 수 있어 `int` 오버플로를 피하기 위해 `long`으로 계산한다.

## 복잡도
- 시간복잡도: O(√n) — `i * i`가 `n`을 넘을 때까지 최대 √n번 반복.
- 공간복잡도: O(1).
