# 콜라츠 추측 (12943)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12943
- 난이도: Lv.1

## 문제 요약
자연수 `num`에 대해 다음 규칙을 반복 적용했을 때 1이 될 때까지 걸리는 횟수를 구한다.
- 짝수면 2로 나눈다.
- 홀수면 3을 곱하고 1을 더한다.

500번을 시도해도 1이 되지 않으면 -1을 반환한다.

## 접근
- 주어진 수를 1이 될 때까지 반복문으로 변환하면서 횟수를 센다.
- 중간값이 `int` 범위를 넘을 수 있어 Java에서는 `long`으로 계산한다.
- 반복 횟수가 500에 도달했는데도 1이 아니면 즉시 -1을 반환한다.

## 복잡도
- 시간복잡도: O(500) → 반복 횟수가 최대 500회로 고정되어 있어 사실상 O(1).
- 공간복잡도: O(1).
