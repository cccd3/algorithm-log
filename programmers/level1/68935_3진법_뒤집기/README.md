# 3진법 뒤집기 (68935)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/68935
- 난이도: Lv.1

## 문제 요약
자연수 `n`이 주어질 때, `n`을 3진법 표현으로 바꾼 뒤 각 자리를 뒤집어서 다시 10진법 수로 반환한다.

## 접근
- `n`을 3으로 나눈 나머지를 순서대로 이어 붙여 3진법 표현(뒤집힌 순서)을 문자열로 얻는다.
- 이 문자열을 그대로 앞에서부터 읽으며 `result = result * 3 + digit` 방식으로 누적하면 자릿수가 뒤집힌 값이 된다.

## 복잡도
- 시간복잡도: O(log₃ n) — 3진법 자릿수만큼 반복.
- 공간복잡도: O(log₃ n) — 자릿수 저장용 문자열.
