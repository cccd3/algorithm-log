# 행렬의 덧셈 (12950)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12950
- 난이도: Lv.1

## 문제 요약
행렬 두 개(`arr1`, `arr2`)가 주어질 때, 두 행렬을 더한 결과를 반환한다. 두 행렬의 크기는 항상 같다.

## 접근
- `arr1`과 같은 크기의 결과 배열을 만든다.
- 모든 행/열 인덱스를 순회하며 `arr1[i][j] + arr2[i][j]`를 결과 배열에 저장한다.

## 복잡도
- 시간복잡도: O(N × M) — `N`, `M`은 행렬의 행/열 크기.
- 공간복잡도: O(N × M) — 결과 행렬 저장.
