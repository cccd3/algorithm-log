# 완주하지 못한 선수 (Lv.1)

- 문제 번호: 42576
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42576

## 문제 요약
수많은 마라톤 선수 중 단 한 명이 완주하지 못했다. 참가한 선수 배열 `participant`와
완주한 선수 배열 `completion`이 주어질 때, 완주하지 못한 선수의 이름을 반환한다.

## 접근
- 해시(딕셔너리)에 참가자 수를 세고, 완주자를 하나씩 차감한다.
- 남은 사람이 완주하지 못한 선수.

## 복잡도
- 시간: O(n)
- 공간: O(n)
