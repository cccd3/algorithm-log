# 자연수 뒤집어 배열로 만들기 (12932)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12932
- 난이도: Lv.1

## 문제 요약
자연수 `n`을 뒤집어 각 자리 숫자를 원소로 갖는 배열을 반환한다. (1의 자리부터 순서대로)

## 접근
- `n`의 자릿수를 먼저 세어 결과 배열의 길이를 정한다.
- `n % 10`으로 마지막 자리를 꺼내 배열에 채우고 `n /= 10`으로 한 자리씩 줄여나간다.
- `long`을 입력으로 받아 `n`의 범위가 커져도 오버플로 없이 처리한다.

## 복잡도
- 시간복잡도: O(d) — `d`는 `n`의 자릿수.
- 공간복잡도: O(d) — 결과 배열 크기.
