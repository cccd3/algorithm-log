# 문자열 다루기 기본 (12918)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12918
- 난이도: Lv.1

## 문제 요약
문자열 `s`의 길이가 4 혹은 6이고, 모든 문자가 숫자로만 이루어져 있는지 판별한다.

## 접근
- 먼저 길이가 4 또는 6이 아니면 바로 `false`를 반환한다.
- 문자열의 각 문자를 순회하며 `'0'`~`'9'` 범위를 벗어나는 문자가 있으면 `false`를 반환한다.
- 두 조건을 모두 통과하면 `true`를 반환한다.

## 복잡도
- 시간복잡도: O(L) — `L`은 문자열의 길이(최대 8).
- 공간복잡도: O(1).
