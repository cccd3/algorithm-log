# n개 간격의 원소들 (181888)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/181888
- 난이도: Lv.0

## 문제 요약
정수 리스트 `num_list`와 정수 `n`이 주어질 때, 첫 번째 원소부터 `n`개 간격으로 위치한 원소들을 순서대로 담은 리스트를 반환한다.

## 접근
- 인덱스 `0`부터 시작해 `n`씩 증가시키며 `num_list`의 원소를 순회한다.
- 순회한 값을 리스트에 담고, 마지막에 배열로 변환해 반환한다.

## 복잡도
- 시간복잡도: O(n) — 배열 길이에 비례해 최대 한 번씩만 순회.
- 공간복잡도: O(k) — 결과로 반환하는 원소 개수만큼의 리스트를 사용.
