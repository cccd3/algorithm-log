# 수열과 구간 쿼리 3 (181924)

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/181924
- 난이도: Lv.0

## 문제 요약
정수 배열 `arr`과 쿼리 목록 `queries`가 주어질 때, 각 쿼리 `[i, j]`마다 `arr[i]`와 `arr[j]`를 순서대로 교환한 뒤 최종 배열을 반환한다.

## 접근
- 쿼리를 순서대로 순회하며 두 인덱스의 값을 임시 변수를 이용해 스왑한다.
- 모든 쿼리 처리가 끝난 배열을 그대로 반환한다.

## 복잡도
- 시간복잡도: O(n) — 쿼리 개수만큼 스왑 1회씩 수행.
- 공간복잡도: O(1) — 스왑용 임시 변수만 사용.
